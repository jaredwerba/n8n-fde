# Writing rules for these docs

These project docs follow ASD-STE100 (Simplified Technical English), issue 9, as a writing standard. This file is not a copy of the specification. The specification is copyright ASD-STE100.

Use these rules in `docs/projects/` and in `docs/n8n-instance.md`.

1. Write one topic in each sentence.
2. In a procedure, use a maximum of 20 words in a sentence.
3. In a description, use a maximum of 25 words in a sentence.
4. Write procedures in the active voice. Start each step with a verb.
5. Use the simple present, the simple past, the simple future, or the imperative.
6. Do not use the present perfect. Write "The check found" and not "We found it earlier".
7. Do not use a semicolon. Write two sentences.
8. Do not use a contraction.
9. Do not omit the verb, the subject, or the article to make a sentence short.
10. Do not put more than three nouns in a row as a modifier.
11. Use "must" for an obligation. Use "can" for an option.
12. Put a warning before the step that can cause the problem.

Approved short forms in these docs: n8n, JSON, API, HTTP, URL, FDE, STE, DONKI, NASA.

If a sentence in `docs/projects/` breaks a rule above, correct the sentence. Do not add a note that the sentence is an exception.
